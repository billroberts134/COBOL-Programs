## Core Technical Skills

* **z/OS & Spool Management:** TSO/ISPF navigation, dataset allocation, PDS management, and job output/log inspection using SDSF.
* **Batch Processing & JCL:** Writing and troubleshooting Job Control Language (`JOB`, `EXEC`, `DD`), condition code handling (`COND` / `IF-THEN-ELSE`), Generation Data Groups (GDGs), and standard IBM utilities (`IDCAMS`, `IEBGENER`, `DFSORT`).
* **COBOL & Debugging:** Reading, maintaining, and testing Enterprise COBOL batch programs, sequential/indexed file handling, copybooks, and diagnosing runtime abends (such as `S0C7` data exceptions and file status errors).
* **Data & Tooling:** VSAM (KSDS/ESDS), VS Code with IBM Z Open Editor and Zowe Explorer, 3270 terminal emulation, and GnuCOBOL (plus foundational awareness of Db2 and CICS).
