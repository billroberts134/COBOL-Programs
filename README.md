Repository Structure * 
**Source Files:** All main program files (e.g., `.cbl`, `.cob`) are organized within the project directories. * **Data Files:** Sample input/output sequential or indexed
files used for processing calculations and reports. ## 🚀 
Key Highlights & Concepts Covered * 
**Structured Programming:** Clean separation of `IDENTIFICATION`, `ENVIRONMENT`, `DATA`, and `PROCEDURE` divisions. * 
**File Handling:** Utilizing `SELECT/ASSIGN` statements, open/close operations, and sequential file reading loops (`PERFORM UNTIL`). * 
**Data Manipulation:** Implementing precise arithmetic operations, data movement (`MOVE`), and edited pictures (`PIC`) for clean report layouts. * 
**Control Structures:** Conditional processing via `EVALUATE` and `IF/THEN/ELSE` blocks. ## 🛠️ Environment & Compiling 

To compile and run these programs locally, 
you can use an open-source compiler like **GnuCOBOL**. 1. **Compile a program:** ```bash cobc -x -o program_name program_name.cbl ``` 
2. **Run the compiled binary:** ```bash ./program_name ```
